A comprehensive collection of interactive Power BI dashboards designed for sales performance evaluation, profitability analysis, and financial reporting. The reports leverage custom DAX formulas, interactive cross-filtering, and modern data visualizations to deliver actionable business intelligence across products, global markets, and timelines.

---

## 🌟 Features

- **Executive KPI Monitoring**: Instant visibility into high-level business metrics including Total Revenue ($4.69M), Total Profit ($2.76M), Total Cost ($2.0M), and Average Profit.
- **Custom DAX Calculations**: Advanced measure modeling for revenue per unit, cost analysis, margin computations, and aggregated performance tracking.
- **Geographic Performance**: Country-level breakdown of sales volume and profitability across major regions (United States, Canada, France, Mexico, Germany).
- **Product Portfolio Analysis**: Detailed evaluation of unit costs, revenues, and net margins across individual product lines.
- **Temporal & Trend Insights**: Time-series analysis featuring monthly profit curves, year-over-year unit sales (2018 vs. 2019), and multi-line profit trends per product category.
- **Interactive Visual Elements**: Modern gauge visuals for cost/profit targets, donut share breakdowns, monthly volume treemaps, and dynamic slicers for deep dives.

## 🚀 Getting Started

### Prerequisites

To view the dashboard exports:
- Any modern web browser (Google Chrome, Microsoft Edge, Firefox) or a PDF reader (Adobe Acrobat Reader).

To edit or build similar reports:
- [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/) (Windows).

### Installation

Clone the repository locally:

```bash
git clone https://github.com/Joeljozzz/Powerbi-dashboards.git
cd Powerbi-dashboards
```

## 💡 Usage

1. Open any of the `.pdf` report files in your preferred PDF viewer or web browser.
2. Review the layout, visual hierarchies, and DAX metric formulations across each report iteration.
